This is a SECRET: the Death Knight must not appear in README, release notes, CHANGELOG or commit messages. Use neutral wording such as "content" or "hidden unlock" there. Code comments may name it.

## Track A: progression (branch `feat/progression`, worktree `~/Projects/azs-progression`)

### 1. Limit Break
When the player has nothing left to offer (all weapon and passive slots full and maxed, or nothing eligible), level-up cards offer endless small stacking bonuses instead of gold:
- +3% damage
- +10 max HP
- +2% crit
- -2% cooldown (floor at 50% total)
- +5% area
- +4% speed (cap +40%)
- +5% pickup range
- +1 projectile to every proj, fan and missile skill (offered at most every 5th Limit Break pick)

Also:
- The cards show the current stack ("Might +12%").
- Store the stacks in `S.limit` (saved).
- Show them as a compact line on the HUD or the pause screen.

### 2. Endless
At 10:00 the victory is recorded at that moment: achievements, best time, gold banked so far, and the guild board. Then a panel offers **Cash out** (results screen) or **Keep going** (Endless).

In Endless:
- Spawn and hp scaling continue faster past 600 s.
- The Frost Lich returns every 5 min, stronger each time.
- Gold per kill grows +10% per extra minute.
- The run ends on death or quit. The results screen shows "Endless +m:ss", and the leaderboard and best records keep the longest time.

Other rules:
- Guild message: extend the format compatibly by appending `:endless_seconds` at the end. Old parsers ignore extra fields; check Social.lua's parser accepts both.
- Saves work in Endless.
- Gold banking must not double count. Bank at 10:00, then bank only the gold earned after that when the run ends.

### 3. A bigger shop
Add these items, with steep cost growth so gold always has a sink:

| Item | Effect | Ranks |
|---|---|---|
| Revival | +1 revive per run, restores 50% HP with 2 s invulnerability and a screen flash | 2 |
| Amount | +1 projectile/count on every skill that has count | 1, very expensive |
| Cooldown | -3% cooldown | 5 |
| Area | +5% | 5 |
| Luck | chests roll +1 extra upgrade with 15% chance per rank; more gold drops | 3 |
| Banish | Banish N offers for the run: a key on level-up (B) removes that card's skill/passive from all future offers | 3 |
| Magnet | +10% pickup range | 2 |

Also add "Prestige" ranks to the old stat items (Might, Max HP, Recovery, Growth): ranks 6-10 at much higher cost (grow 1.9), unlocked after owning all base ranks.

The shop panel must stay readable at 1000x700. Use two columns or scrolling with the mouse wheel; keep the text from overlapping and test the layout like the existing title-layout check.

### 4. Ascension
Per class, `db.asc[class] = highest unlocked level`. Level 1 unlocks when that class wins (reaches 10:00) with all 4 curses. Each win at the current top level unlocks the next, up to A10.

- The class screen gets an Ascension selector (- / +) for the selected class, shown only when unlocked.
- The chosen level is stored in `db.ascSel[class]` and passed to Sim via opts.

Each level adds the previous levels' twists plus its own:

| Level | Twist |
|---|---|
| A1 | elites every 45 s |
| A2 | enemies +10% speed |
| A3 | boss at 7:00 |
| A4 | -1 level-up choice (min 2) |
| A5 | enemy projectiles +50% |
| A6 | potions heal half |
| A7 | elites +50% hp |
| A8 | +25% spawn |
| A9 | chests give one fewer upgrade (min 1) |
| A10 | the boss enrages at half hp (+50% speed and damage) |

Rewards: gold +20% per level. The results screen, guild board and best records show "A<n>". The board line format appends `:asc` (compatible as above).

- Class select: 6 cards in 2x3 stay as now. When unlocked, a 7th card fits without overlap: switch to a 2x4 grid of smaller cards or a centred third row. Update the title-layout test to cover both cases. Key 7 selects it.
